# Development

Day-to-day commands for working in the monorepo. The top-level scripts run
through [Turborepo](https://turborepo.com), fanning out across every workspace.

```bash
pnpm dev         # start the dev servers with Turbopack
pnpm build       # production build (in apps/app this runs drizzle-kit migrate, then next build)
pnpm lint        # ESLint
pnpm typecheck   # tsc --noEmit
pnpm format      # Prettier
pnpm test        # Vitest (run from apps/app for watch mode: pnpm test:watch)
```

## Database

Run these from `apps/app`:

```bash
pnpm db:generate # generate a new SQL migration from schema changes — commit the output
pnpm db:migrate  # apply committed migrations to $DATABASE_URL
pnpm db:push     # push the schema directly without a migration file (throwaway dev only)
pnpm db:studio   # open Drizzle Studio
```

See [Database](/deployment/database) for the schema overview and the
generate-then-commit migration workflow.

## Screenshots for design review

Design-polish tickets ship before/after screenshots on the PR. The screenshot
harness boots the local build against a seeded fixture world and captures a
named list of screens in light and dark:

```bash
pnpm --filter app screenshots:boot    # a browsable, fully-populated local build
pnpm --filter app screenshots:shots   # capture the named screens, both themes
```

See [Screenshots for design review](/screenshots) for the before/after workflow,
how to add a screen, and what the local build leaves out.
