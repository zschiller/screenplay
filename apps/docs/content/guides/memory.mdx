# Memory

Memory is short notes chats follow without being told again: a preference
like "Write UI copy in plain sentences", a decision, or a fact about a
repository like "Use pnpm, never npm." Nothing in memory shows on the canvas.
Chats read it at the start of every message.

There are two kinds:

| Memory             | Whose                | Who reads it                                         | Where you manage it              |
| ------------------ | -------------------- | ---------------------------------------------------- | -------------------------------- |
| **Account memory** | Yours                | Every chat you send a message in, on any canvas      | **Settings** › **Memory**        |
| **Canvas memory**  | The canvas's members | Every chat on that canvas, whoever sends the message | **Canvas settings** › **Memory** |

Put what follows you everywhere (how you like things written, how big a
change you prefer) in account memory, and what's about one canvas's work in
its canvas memory. Each chat reads both: your account memory, then the
canvas's.

## Account memory

Open **Settings** from the bottom of the home screen sidebar and choose
**Memory**. **Add memory** adds an entry, **Edit** changes one, and **…** ›
**Delete** removes it. Each row says whether an agent saved it or you added it.

On a shared canvas, a chat reads the account memory of whoever sent the
message, not of whoever started the chat. A message you send in a teammate's
chat follows your account memory, and theirs never steers it. Messages the
Coordinator sends on its own, when a workspace finishes, read no one's
account memory.

Account memory works the same on the desktop app, where it belongs to the
one person using the app.

## Canvas memory

The Coordinator saves to canvas memory when you tell it something worth
keeping or ask it to remember something, and it edits or removes entries when
you ask.

To read or change it yourself, open **Canvas settings** from the **…** next
to the canvas name and choose **Memory**. **Edit** changes an entry, **…** ›
**Delete** removes it (<kbd>⌘</kbd> <kbd>Z</kbd> on the canvas brings it
back), and **Add memory** adds one. Everyone on a shared canvas sees the same
entries.

## Limits

An entry holds up to 1,000 characters; memory is notes, not documents. When a
list grows past 100 entries, chats read the newest 100. On the desktop app, a
chat that runs through an external harness gets memory when the chat starts.
Never put secrets or credentials in memory.
