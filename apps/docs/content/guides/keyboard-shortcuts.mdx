# Keyboard shortcuts

On Windows and Linux, use <kbd>Ctrl</kbd> wherever you see <kbd>⌘</kbd>.
Single-key shortcuts are ignored while you're typing in a text field or
document, and so is every canvas key while a menu or dialog is open. In a
document, <kbd>⌘</kbd> <kbd>B</kbd> and <kbd>⌘</kbd> <kbd>I</kbd> format the
text instead of toggling the panels.

## Canvas

| Shortcut | Action |
| --- | --- |
| <kbd>V</kbd> | Select tool |
| <kbd>F</kbd> | Frame tool (press again to go back to Select) |
| <kbd>D</kbd> | Document tool |
| <kbd>C</kbd> | Comment tool *(hosted)* |
| <kbd>/</kbd> | Cursor chat: a message next to your cursor that collaborators see |
| <kbd>Space</kbd> + drag | Pan |
| Scroll | Pan |
| <kbd>⌘</kbd> + scroll, or pinch | Zoom |
| <kbd>⌘</kbd> <kbd>=</kbd> / <kbd>⌘</kbd> <kbd>-</kbd> | Zoom in / out |
| <kbd>⌘</kbd> <kbd>0</kbd> | Zoom to 100% |
| <kbd>⇧</kbd> <kbd>1</kbd> | Zoom to fit |
| <kbd>⇧</kbd> + click | Add to or remove from the selection |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Delete the selection |
| <kbd>⌘</kbd> <kbd>Z</kbd> | Undo |
| <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>Z</kbd> | Redo |
| <kbd>Esc</kbd> | Back out one step (see below) |

## Panels

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>B</kbd> | Toggle the left sidebar |
| <kbd>⌘</kbd> <kbd>I</kbd> | Toggle the agent panel |
| <kbd>⌃</kbd> <kbd>`</kbd> | Open or close a workspace's terminal pane |
| <kbd>⌘</kbd> <kbd>.</kbd> | Hide both panels, or show both |
| <kbd>?</kbd> | Show the keyboard shortcuts sheet |

## Moving and resizing

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> while resizing a frame | Resize freely, without snapping to device sizes |
| <kbd>⌘</kbd> while reordering in a group | Pull the layer out into a new group |
| <kbd>⌘</kbd> while dragging a group | Move without merging into another group |

## Composer

| Shortcut | Action |
| --- | --- |
| <kbd>↵</kbd> | Send |
| <kbd>⇧</kbd> <kbd>↵</kbd> | New line |
| <kbd>@</kbd> | Mention a document |
| <kbd>/</kbd> | Insert a skill *(workspace chats)* |
| <kbd>⌘</kbd> <kbd>E</kbd> | Target an element in a frame |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>↵</kbd> or <kbd>Tab</kbd> | Navigate and pick in the @ and / menus |
| <kbd>⌘</kbd> <kbd>I</kbd> | Hide the agent panel |
| <kbd>Esc</kbd> | Leave the composer |

## Create workspaces dialog

| Shortcut | Action |
| --- | --- |
| <kbd>↵</kbd> | Create all workspaces |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Add another row |
| <kbd>⇧</kbd> <kbd>↵</kbd> | New line in a prompt |
| <kbd>Backspace</kbd> in an empty row | Remove that row |

## Comments *(hosted)*

| Shortcut | Action |
| --- | --- |
| <kbd>⌘</kbd> <kbd>↵</kbd> | Post a comment or reply |
| <kbd>J</kbd> / <kbd>K</kbd> | Next / previous thread in the Comments panel |
| <kbd>E</kbd> | Resolve or reopen the chosen thread in the Comments panel |

## Renaming

Frame, document, group and canvas names, and workspace titles in the
Chats menu, rename in place.

| Shortcut | Action |
| --- | --- |
| <kbd>↵</kbd> or <kbd>F2</kbd> on a focused name in the sidebar or on the canvas | Start renaming |
| <kbd>↵</kbd> | Save the new name |
| <kbd>Esc</kbd> | Cancel, and keep the menu or selection as it was |

## What Escape does

<kbd>Esc</kbd> undoes one thing per press, in this order:

1. Cancels element targeting (if the composer is waiting for a pick)
2. Closes cursor chat
3. Stops editing a document
4. Leaves the Document tool
5. Leaves the Frame tool
6. Leaves the Comment tool, or cancels a comment in progress
7. Closes the Comments panel
8. Leaves Interact mode
9. Stops create flow
10. Clears the selection
