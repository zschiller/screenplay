# Mockups

A mockup is a single static page a chat draws on the canvas to show a
design idea. It needs no dev server, so it appears the moment it's written.
Mockups let you compare a few options side by side with the running app
before anything is built.

Ask a workspace chat for it in your own words, for example "sketch three
takes on the empty cart as mockups". The chat writes each take as its own
mockup, and when you ask for changes it rewrites them in place.

## Where mockups sit

- **Beside a frame.** A chat's first mockup joins the group of its
  workspace's frames, so the live page and the options read left to right in
  one row.
- **Beside each other.** Every later mockup from the same chat joins the
  group of its previous one.
- **On their own.** When the chat's workspace has no frame on the canvas yet,
  its mockups get a group of their own.

## Which chat made it

Every mockup remembers the chat that made it, and shows that chat's
workspace next to its title, as a chat's documents do. When everything in a
group comes from the same workspace, the group's label names it once instead.
Only the chat that made a mockup can change it; ask that chat to continue the
work.

## Status

Each mockup shows a status at the end of its label: **Set aside**,
**Current** or **Built**. A new mockup starts as Current. Click the status
to change it, and everyone on the canvas sees the change. The chat that made
the mockup can set it too, for example marking a take Built once it's in the
app. The status is only a note for people following the takes; it doesn't
change how the mockup looks or behaves.

## Working with mockups

Mockups are layers like frames and documents. You can select, move, resize,
rename and delete them, group them with other layers, and find them in the
layers list with their own icon. Delete them with <kbd>Delete</kbd>, and

<kbd>⌘Z</kbd> brings a deleted mockup back.

A mockup is a picture of an idea, so clicking it selects it rather than
using the page. It has no address bar, reload or Interact. Mockups aren't
chat targets, and there's no toolbar tool for them: chats create them.

## Safety

A mockup's page runs in a locked-down frame: it can run its own scripts, but
it can't reach Screenplay, your session or the rest of the canvas, and it
doesn't load anything from the network. Mockups are self-contained pages.
