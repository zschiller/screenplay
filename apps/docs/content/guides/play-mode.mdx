# Play mode

**Play mode** opens a chat’s app full screen, with
no canvas around it. Use it to test a flow properly or present a prototype.

<Screenshot
  name="play-desktop"
  alt="Play mode showing the Northwind homepage full screen, with the player controls in the corner"
/>

Open it from:

- a chat’s **… → Open in play mode**, or
- a frame’s **… → Preview → Open in play mode**. Play mode opens on that
  frame’s route and with its knob values.

Play mode opens in a new browser tab (on desktop, in your default browser),
titled **▶ _canvas name_**. Its link opens play mode on the route and knob
values the frame had when you opened it; it doesn’t follow you as you click
around. On the hosted app, anyone with access to the canvas can open the
link.

## The player controls

A small bar in the corner holds the controls. Drag it by its handle to any
corner; the position is remembered.

<Screenshot name="play-hud" alt="The player control bar" />

| Control                    | What it does                                                                                                                                          |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **← Back to _canvas_**     | <Only hosted /> Returns to the canvas.                                                                                                                |
| **Device**                 | Switches device size without reloading, so you stay on the same page. Phones and tablets appear in a device outline, scaled to fit, with touch input. |
| **Knobs**                  | Opens the knobs panel.                                                                                                                                |
| **Comment** (<kbd>C</kbd>) | <Only hosted /> Comment on an element of the live page, anchored the same way as comments on a frame.                                                 |
| **Comments**               | <Only hosted /> This chat’s comment threads, the current route’s first. The same threads show on the canvas.                                          |
| **Show chat**              | Opens this chat in a side panel, so you can ask for changes while you test.                                                                           |

<Screenshot name="play-device-menu" alt="The device menu in play mode" />

## Mobile sizes

Pick a phone to preview inside a device outline. Pointer input switches to
touch, so tap targets and scrolling behave like the real device.

<Screenshot
  name="play-mobile"
  alt="Play mode showing the homepage inside an iPhone 17 Pro outline"
/>

## Knobs and the agent

**Knobs** opens the same controls as the frame’s knobs popover, with a
**Reset** button. Knob changes in play mode apply to play mode only; the
frame on the canvas keeps its own values.

<Screenshot name="play-knobs" alt="Play mode’s Knobs panel" />

**Show chat** docks the chat beside the app. The preview
updates live as the agent changes the code.
