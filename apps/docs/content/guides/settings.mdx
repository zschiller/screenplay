# Settings

Open **Settings** from the bottom of the home screen sidebar, under **Docs**.
A list on the left picks the section: **General**, then on desktop **Coding
agents** and **GitHub** (on the hosted app, **Agent**), then **Repositories**,
**Memory**, **Files**, **Skills** and **Account**.

<Screenshot name="settings" alt="The Settings page: the section list and General" />

These are your own settings. A canvas's repositories and their run settings
are in its **Canvas settings**; see [Repositories](/guides/repositories).
Canvas settings also lists the canvas's [memory](/guides/memory) and
[skills](/building/skills#saving-a-skill-to-the-canvas).

## General

The **Theme**: **Light**, **Dark**, or **System**. This setting applies to
this device only.

## GitHub *(desktop)*

GitHub access is **optional** on desktop. Without it you can still add
repositories by local folder or clone URL, and git uses your machine's own
credentials. With it, you can also browse your GitHub repositories and
branches, and open pull requests.

Screenplay finds a token in this order:

1. **The `gh` CLI**, if it's installed and signed in. Nothing else to do: the
   row reads **Connected**, with your `@handle`.
2. **A device code.** Choose **Connect with a device code instead**, enter the
   code on GitHub, and you're connected. The token is kept in your OS
   keychain. **Disconnect** removes it.

If `gh` isn't installed, **Install & connect** installs it (with Homebrew
when available) and runs its sign-in in an inline terminal. The row updates by
itself when sign-in finishes.

<Callout type="info">
  Screenplay never signs you out of `gh`, since that login is yours and other
  tools use it too. **Disconnect** only removes a device-code token Screenplay
  stored.
</Callout>

On the hosted app, GitHub comes from your sign-in instead: you sign in with
GitHub, and Screenplay uses that account for cloning, pushing, and PRs.

## Agent *(desktop)*

On desktop, the agent is a coding CLI on your machine. There's one row per
supported CLI: **Claude Code**, **Codex**, and **opencode**. Each row shows
whether it's **Signed in**, **Signed out** or **Not installed**:

- **Install and sign in** installs the CLI, then runs its own login in an inline
  terminal.
- **Sign in** appears when it's installed but signed out.
- **Sign in again** appears when it's already connected.

If an install or sign-in doesn't finish, the row says so under its name, and
the same button tries again.

**Default model**, at the top of the section, picks the agent and model that
new chats and new workspaces start with. The hosted app has the same choice in
its own **Agent** section.

A CLI you connect here shows up in the model picker and the new-terminal menu
straight away, with no restart. The app never uninstalls a CLI or signs you
out of it.

## Repositories

Your repositories and how each one runs. They're grouped by repository; **Edit**
or **Delete** each one, or click **New repository** beside the section title
to pick one and confirm its detected settings. Saving an edit here updates
every canvas that uses the repository, unless that canvas customized it. See
[Your repositories](/guides/repositories#your-repositories) for what each one
holds.

## Memory

Your **account memory**: preferences every chat you send a message in
follows, on any canvas, like "Write UI copy in plain sentences." **Add
memory** beside the section title adds one, **Edit** changes one and **…** ›
**Delete** removes it. Each row says whether an agent saved it or you added
it. See [Memory](/guides/memory).

## Files

Your **account files**: files every chat you message can open, on any canvas.
Agents save and organize them; you can open and delete them here. See
[Files](/guides/files#account-files).

## Skills

Your **account skills**: procedures every chat you message can follow, on any
canvas. **Open** shows one, and **…** › **Delete** removes it. To add or change
one, ask a chat. See
[Agent skills](/building/skills#saving-a-skill-to-your-account).

## Account

On the hosted app, this shows who you're signed in as, with **Sign out**. Your
name and photo at the bottom of the home sidebar open a menu with **Sign out**
too. On desktop there's no sign-in, and this shows the app's version.
