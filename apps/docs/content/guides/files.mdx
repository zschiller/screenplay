# Files

Canvas files are files chats keep for later chats on the same canvas:
research notes, a reference image, a PDF. Nothing in them shows on the
canvas. Every chat on the canvas sees the list of files and opens the ones it
needs, so a later chat can pick up what an earlier one saved.

Agents organize the files. Ask a chat to save something, put files in a
folder, rename one or tidy up, and it does. People browse them and can delete
them, but don't add, rename or move files themselves.

## Browsing a canvas's files

Open **Canvas settings** from the **…** next to the canvas name and choose
**Files**. The files show as one tree: folders first, each with how many items
it holds, then files. Click a folder's arrow to expand or collapse it. Each
file says its size and who added it: **Saved by agent**, or the member who
added it.

**…** › **Open** shows a file in its own window over Canvas settings: images
and PDFs as they look, text and code as plain text, and anything else as a
download. **Download** saves a copy.

On the desktop app, **Open** opens the file in its own app on your Mac, the
way double-clicking it in Finder would, and **…** › **Reveal in Finder** shows
a file or folder in Finder. These are copies the app keeps up to date as
agents save, move and delete files; edits you make to them don't reach
chats.

## Deleting

**…** › **Delete** deletes a file, or a folder with everything in it, for
everyone on the canvas. It asks first, naming the file or saying how many
items a folder holds, and can't be undone. Chats can no longer open what you
delete.

Everyone on a shared canvas sees the same files, and only the canvas's
members can open them. Files work the same on the desktop app.
