# Documents

Documents are rich-text pages that live on the canvas next to your previews.
Use them for specs, launch checklists, research notes, or anything the team
and the agent should share.

## Creating and editing

- Press <kbd>D</kbd> (or pick **Document** in the toolbar), then click to
  drop a document or drag to draw one. It opens straight into editing.
- **Double-click** a document to edit it. <kbd>Esc</kbd> or clicking outside
  stops editing.
- The first heading is always the document's **title**. It's also shown in
  the title bar and the layers list.

Select text to open the formatting toolbar. Its first menu shows the block's
current type (for example **Text**) and converts the block (text, headings
1–3, bullet or numbered list, quote, code block). The
buttons apply bold, italic, strikethrough, inline code, and lists. In the
hosted app the toolbar then has **Comment**, which starts a thread on the
selected text (see [Comment on document text](/guides/collaboration#comment-on-document-text)).
The last button, **Reply in chat**, [asks an agent about the passage](#ask-an-agent-about-a-passage).

<Screenshot

/>

Several people can edit the same document at once, and each person's cursor
shows in their color. Documents are layers like frames: you can move them,
resize them, and group them with frames.

## Ask an agent about a passage

Select text in a document and click **Reply in chat** (the curved arrow at the
end of the formatting toolbar). On a document a chat wrote, the passage goes
into that chat's composer and the panel switches to it. On a document you made
yourself, it goes into the chat the agent panel is showing, whether that's the
[Coordinator](/guides/coordinator) or a workspace's chat. Either way the panel
opens if it was closed. This works the same in the web app and the desktop
app.

The quote sits above the input with the document's title, the line range and
the first lines of the text. Type your question and send: the agent gets the
document, the lines and the passage along with it. Nothing is sent until you
do. Click **×** on the quote to drop it, or select other text and click
**Reply in chat** again to replace it.

## Mentioning other documents

Type <kbd>@</kbd> in a document to link to another document on the canvas.
The mention follows the target if it's renamed. <kbd>@</kbd> works the same
way in the [agent composer](/guides/agent#mentioning-documents): the agent is
told which documents you mentioned and reads their current contents.

## Documents a chat writes

A [workspace's chat](/guides/agent) can write documents: ask it for a plan, a
spec or release notes and it drops a new document beside that workspace's
frames. The document shows the workspace's name next to its title, the same
way a group does, unless the group around it already says it. Documents you
make yourself show no name. On a canvas with no repository, ask the
[Coordinator](/guides/coordinator) instead: with no workspaces yet, it writes
documents itself.

A chat edits only the documents it wrote. It can rewrite the body, append to
it and change the title, and its edits merge live into the shared document, so
it never overwrites what you're typing. Every chat can read every document,
but to have a chat change one you made, ask it to write a new one or edit the
text yourself. The agent's tool calls show as **Create document**, **Rewrite
document**, **Append to document**, **Set title** and **Read document** rows.

Comments go to the same place. **Send to agent** on a thread on a chat's
document sends it to the chat that wrote it. On a document you made, it goes
to the workspace chat the agent panel is showing.
