# Documents

Documents are rich-text pages that live on the canvas next to your previews.
Use them for specs, launch checklists, research notes, or anything the team
and the agent should share.

<Screenshot
  name="doc-chat"
  alt="A 'Pricing launch checklist' document on the canvas, with its document chat open"
/>

## Creating and editing

- Press <kbd>D</kbd> (or pick **Document** in the toolbar), then click to
  drop a document or drag to draw one. It opens straight into editing.
- **Double-click** a document to edit it. <kbd>Esc</kbd> or clicking outside
  stops editing.
- The first heading is always the document's **title**. It's also shown in
  the title bar and the layers list.

Select text to open the formatting toolbar. Its first menu shows the block's
current type (for example **Text**) and converts the block (text, headings
1–3, bullet or numbered list, quote, code block). The
buttons apply bold, italic, strikethrough, inline code, and lists.

<Screenshot
  name="doc-selection-toolbar"
  alt="The selection toolbar over a highlighted bullet in the checklist"
/>

Several people can edit the same document at once, and each person's cursor
shows in their color. Documents are layers like frames: you can move them,
resize them, and group them with frames.

## Mentioning other documents

Type <kbd>@</kbd> in a document to link to another document on the canvas.
The mention follows the target if it's renamed. <kbd>@</kbd> works the same
way in the [agent composer](/guides/agent#mentioning-documents): the agent is
told which documents you mentioned and reads their current contents.

## Chatting with a document

Every document can be a chat target. Pick it under **Documents** in the agent
panel's Workspaces menu. The agent then acts as an editor for that page. It can:

- rewrite the body,
- append to it,
- change the title,
- read other documents on the canvas.

<Screenshot
  name="workspaces-menu"
  alt="The Workspaces menu listing the Coordinator, Workspaces and Documents"
/>

Edits merge live into the shared document, so the agent never overwrites what
you're typing. Document chats don't have a sandbox, so there are no shell
commands, git, skills, plan mode, or terminals.

## Sending a selection to the agent

Select text in a document to reference it in a chat. The quoted passage and
its line numbers are sent to a **fresh** chat on that document, so you can
say "tighten this paragraph" without copying anything. On the hosted app this
is the **Send to agent** button in the comment box. On desktop, where comments
aren't stored, it's the box's main action.
