# Documents

Documents are rich-text pages that live on the canvas next to your previews.
Use them for specs, launch checklists, research notes, or anything the team
and the agent should share.

## Creating and editing

- Press <kbd>D</kbd> (or pick **Document** in the toolbar), then click to
  drop a document or drag to draw one. A card asks what it should say. Type
  what you want and press <kbd>Enter</kbd>, and the chat it names writes the
  title and the page. The chip beside the text picks the chat: a new one, a
  chat’s own, or a chat with no repository.
- To write it yourself, click **Write it myself** or press <kbd>Esc</kbd>.
  The caret goes into the title, and anything you typed in the card becomes
  the title. Clicking away leaves the document empty.
- A selected document has a bar under it with **Edit** and **…** (Rename,
  Duplicate, Duplicate as new file, Remove and Delete file; see
  [Removing and deleting](#removing-and-deleting)). Click **Edit** or **double-click** the document to edit it. While
  you edit, **Edit** turns pink and so does the document’s thicker outline.
  Click **Edit** again, press <kbd>Esc</kbd> or click outside to stop editing.
- The first heading is always the document’s **title**. It’s also shown in
  the title bar and the layers list.

While you edit, the bar under the document adds the block controls. Its menu
shows the current block’s type (for example **Text**) and converts it (text,
headings 1–3, bullet or numbered list, quote, code block). Then comes
**Image**. Both work on the block the caret is in, so
you don’t have to select text first.

Select text to open the formatting toolbar above it. Its buttons apply bold,
italic, strikethrough and inline code. In the hosted app it then has
**Comment**, which starts a thread on the selected text (see
[Comment on document text](/guides/collaboration#comment-on-document-text)).
The last button, **Quote in chat**, [asks an agent about the passage](#ask-an-agent-about-a-passage).

Type <kbd>/</kbd> at the start of a line for the **/ menu**. Its
**Format** group turns the line into text, a heading, a list, a quote or a
code block, or adds a divider. Its **Insert** group adds an
[image](#images) or a [mention](#mentioning-documents-chats-and-mockups).
Keep typing to narrow the list, and press <kbd>Enter</kbd> to pick. Each item
shows the markdown you can type at the start of a line instead, such as `##`
for a heading 2 or `-` for a bullet list.

On the hosted app, several people can edit the same document at once, and
each person’s cursor shows in their color. Documents are layers like frames: you can move them,
resize them, and group them with frames.

## Removing and deleting

Each document is a **file**, and a document on the canvas is a **view** of
it. One file can have several views, all showing the same page, or none at
all.

- <kbd>Delete</kbd>, or **…** › **Remove from canvas**, takes away only that view, and
  <kbd>⌘</kbd> <kbd>Z</kbd> brings it back. A document whose last view goes
  stays in [Files](/guides/files#documents-and-mockups), marked **Not on
  canvas**, and chats and mentions still name it.
- **…** › **Delete file** deletes the document and every view of it at once,
  with no confirm. One <kbd>⌘</kbd> <kbd>Z</kbd> brings them all back. A
  mention of a deleted document shows its name struck through and opens
  nothing.
- **…** › **Duplicate** (<kbd>⌘</kbd> <kbd>D</kbd>) adds another view of the
  same document at the end of its group; an edit in one shows in both.
  **Duplicate as new file** makes a copy, its title ending in “copy”, that you
  edit on its own.

## Images

To put an image in a document, paste it, drag it in from your computer, or
type <kbd>/</kbd> at the start of a line and pick:

- **Upload image** chooses images from your computer.
- **Image from files** lists the images in the canvas’s and your
  [account’s files](/guides/files), newest first, with a search box.

The **Image** button on the bar under the document, while you edit it,
offers the same two and puts the image after the paragraph or list the caret
is in.

An image you paste, drop or upload is saved to the canvas’s files, in the
**uploads** folder, so chats can open it too. An image from your account’s
files is copied there, so everyone on the canvas can see it. A spinner holds
its place while it uploads. Click an image while editing to select it, and
press <kbd>Backspace</kbd> to take it out of the document; the file stays in
Files. If an image’s file is deleted, the document says so where the image
was.

Images show at the size they were on screen, so a screenshot from a retina
display isn’t twice as big as it should be. A PNG that records its
resolution, as macOS screenshots do, and a file named like `chart@2x.png`
show at that density. An image wider than 1000 pixels with neither is shown
at half its width. No image is ever wider than the document.

Documents show PNG, JPEG, GIF and WebP images. A chat that writes a document
can put an image from the canvas’s files in it too.

## Ask an agent about a passage

Select text in a document and click **Quote in chat** (the quote mark at the
end of the formatting toolbar), or press <kbd>⌘</kbd> <kbd>L</kbd>. On a
document a chat wrote or edited, the passage goes into the composer of the
chat that changed it last, and the panel
switches to it. On a document no chat has changed, it goes into the chat the
agent panel is showing, whether that’s the
[Coordinator](/guides/coordinator) or another chat. Either way the panel
opens if it was closed. This works the same in the hosted app and the desktop
app.

The quote sits above the input with the document’s title, the line range and
the first lines of the text. Type your question and send: the agent gets the
document, the lines and the passage along with it. Lines count the document
the way the agent reads it, as markdown with a blank line between paragraphs,
so the agent finds the passage on the line the quote names. Nothing is sent
until you do. Click **×** on the quote to drop it, or select other text and click
**Quote in chat** again to replace it.

## Mentioning documents, chats and mockups

Type <kbd>@</kbd> in a document, or pick **Mention** in the / menu, to link to
another document, a chat or a mockup on the canvas. The list groups them under
**Documents**, **Chats** and **Mockups**; keep typing to narrow it. A mention
follows its target if it’s renamed, and shows its name struck through once
its file is deleted. <kbd>@</kbd> in the
[agent composer](/guides/agent#mentioning-documents) lists documents: the
agent is told which documents you mentioned and reads their current
contents.

## Documents a chat writes

A [chat](/guides/agent) can write documents: ask it for a plan, a
spec or release notes and it writes a new one. Every document a chat writes
or changes shows in its reply as a tile with its opening lines and its name;
click it to read the document in a window over the canvas. The chat decides
whether the document also goes on the canvas, beside that chat’s frames. One
that only answers the chat stays there until you choose **Add to canvas** from
**⋯** in the window’s title row, or ask the chat to put it on the canvas. While a chat is changing a document, its label names that chat with
the working dots, and the document’s row in the sidebar ends in the same dots;
otherwise the label shows only its title. A
[chat with no repository](/guides/agent#chats-with-no-repository) writes
documents too, on a canvas with no repository or beside other chats.

Any chat can edit any document, whether a chat wrote it or you made it
yourself. It can rewrite the body, append to
it and change the title, and its edits merge live into the shared document, so
it never overwrites what you’re typing. A chat reads a document’s formatting,
images and mentions, each mention by its current name, and appending keeps
them all. While a chat is changing a document, it holds it until it finishes: another
chat that tries to change it tells you who has it and carries on. Every
document remembers the chat that changed it last. The agent’s tool calls show as **Create document**, **Rewrite
document**, **Append to document**, **Set title** and **Read document** rows.

In the hosted app, comments go to the same place. **Send to agent** on a thread on a chat’s
document sends it to the chat changing it right now, or else the chat that
changed it last. On a document no chat has
changed, it goes to the chat the agent panel is showing.
