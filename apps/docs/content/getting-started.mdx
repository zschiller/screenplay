# Getting Started

Get the Screenplay monorepo running locally.

## Prerequisites

- [Node.js](https://nodejs.org) 20 or newer
- [pnpm](https://pnpm.io) 9

## Install

```bash
pnpm install
```

## Run

Start every app in the monorepo with Turborepo:

```bash
pnpm dev
```

The docs site (this app) dev-serves on
[http://localhost:3002](http://localhost:3002).
