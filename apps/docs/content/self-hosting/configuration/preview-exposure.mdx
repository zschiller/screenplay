# Preview exposure

<Only desktop />

When Screenplay runs on a machine you control, every chat’s preview runs there
too, and a browser has to reach it. **Preview exposure** decides how. It’s a
small interface in `apps/app/lib/preview-exposure/` with four built-ins:

| Built-in       | Previews bind | A browser loads                           | For                                       |
| -------------- | ------------- | ----------------------------------------- | ----------------------------------------- |
| `loopback`     | `127.0.0.1`   | `http://localhost:{port}`                 | The Mac app (the default)                 |
| `tailscale`    | `127.0.0.1`   | `https://<mac>.<tailnet>.ts.net:{port}`   | Sharing over your tailnet                 |
| `url-template` | `0.0.0.0`     | an origin from a pattern                  | A proxy that gives every port its own URL |
| `command`      | `127.0.0.1`   | an origin from a pattern, after a command | A company tool                            |

On [Headless](/self-hosting/headless), it’s how viewers reach previews. The
host’s own frames always load through portless at
`http://screenplay-<port>.localhost:1355`, over the host’s SSH tunnel, whatever
exposure is picked, so the host never needs a company proxy or its sign-in.

It covers only what a browser loads: each chat’s bridge proxy (the page a
frame shows) and its frame stream. The preview itself always listens on
`127.0.0.1`. The server never loads a browser URL either: its own checks,
thumbnails and the agent’s page reads go to each preview’s `127.0.0.1` address,
so they work whatever URL your browser uses. Hosted sandboxes don’t use it;
each Vercel Sandbox has its own public URL.

## The interface

```ts
interface PreviewExposure {
  // Where browser-facing listeners bind, and the range their ports come from.
  readonly bind: { host: string; ports?: { from: number; to: number } }
  // Make a port reachable, once its listener is started. Idempotent.
  expose(port: number): Promise<{ browserOrigin: string; signInUrl?: string }>
  // Undo expose when the chat is deleted. Never throws.
  release(port: number): Promise<void>
}
```

`signInUrl` is for a proxy that needs a person to sign in once per port, in a
new tab, before that port loads in a frame.

### Ports

With `ports` set, each chat’s browser-facing ports come from that range,
lowest free first, and a deleted chat’s ports are the next ones handed out. A
company proxy that asks for a sign-in per port then asks once per port, not
once per chat. Ports a chat already holds stay its own across restarts.
Without a range, any free port is used. When every port in the range is taken,
a new chat fails with an error saying so: delete a chat, or widen the range.

## Built-ins

Each built-in is a function in `apps/app/lib/preview-exposure/builtins.ts` that
takes its options as an object and refuses one it doesn’t recognise with a
message naming it.

### `loopback`: `loopbackExposure()`

The Mac app’s behaviour, and the default: previews bind `127.0.0.1` and load at
`http://localhost:{port}`.

| Option   | Default                   |                                                       |
| -------- | ------------------------- | ----------------------------------------------------- |
| `origin` | `http://localhost:{port}` | The browser origin pattern                            |
| `ports`  | any free port             | A range, e.g. to match a fixed list of `ssh -L` ports |

### `tailscale`: `tailscaleExposure()`

Shares each port with everyone on your tailnet. Exposing a port runs
`tailscale serve --bg --https=<port> http://127.0.0.1:<port>`, and the port
loads at `https://<mac>.<tailnet>.ts.net:<port>`; releasing it runs
`tailscale serve --https=<port> off`. `--bg` keeps each port served after a
restart until it’s released.

It needs Tailscale installed, signed in and connected, with MagicDNS and HTTPS
Certificates turned on for your tailnet (the DNS page of the Tailscale admin
console). When any of those is missing, the preview shows an error saying
which.

| Option | Default                                                                  |                               |
| ------ | ------------------------------------------------------------------------ | ----------------------------- |
| `cli`  | `tailscale`, then `/Applications/Tailscale.app/Contents/MacOS/Tailscale` | The commands to try, in order |

### `url-template`: `urlTemplateExposure()`

For a proxy that gives every port on the machine its own HTTPS URL. Previews
listen on every interface so the proxy can reach them, so keep the machine’s
ports firewalled from everything but the proxy.

```ts
urlTemplateExposure({
  origin: "https://{port}-box.corp.example",
  signInUrl: "https://{port}-box.corp.example/",
  ports: { from: 20000, to: 20199 },
})
```

| Option      | Default       |                                                   |
| ----------- | ------------- | ------------------------------------------------- |
| `origin`    | required      | The browser origin pattern; must contain `{port}` |
| `signInUrl` | none          | A page to open once per port before it loads      |
| `bindHost`  | `0.0.0.0`     | Where the listeners bind                          |
| `ports`     | any free port | The range ports come from                         |

### `command`: `commandExposure()`

Runs a command to expose each port and another to release it, with `{port}`
filled in, then loads the port at an origin from a pattern. A failed expose
shows the command’s error on the preview; a failed release is only logged.

```ts
commandExposure({
  exposeCommand: ["corp-expose", "{port}"],
  releaseCommand: ["corp-expose", "--release", "{port}"],
  origin: "https://box.corp.example:{port}",
})
```

| Option           | Default       |                                                   |
| ---------------- | ------------- | ------------------------------------------------- |
| `exposeCommand`  | required      | The command and its arguments                     |
| `releaseCommand` | none          | Run when a chat is deleted                        |
| `origin`         | required      | The browser origin pattern; must contain `{port}` |
| `signInUrl`      | none          | A page to open once per port before it loads      |
| `bindHost`       | `127.0.0.1`   | Where the listeners bind                          |
| `ports`          | any free port | The range ports come from                         |

## Picking one

`selectPreviewExposure()` in `apps/app/lib/preview-exposure/index.ts` picks
one: `loopback`, everywhere. `PREVIEW_EXPOSURE` overrides it with `loopback`
or `tailscale`; the other built-ins need options. An id it doesn’t know stops
the server from starting.

`url-template`, `command`, `loopback` with options, or an implementation of
your own is a change to `selectPreviewExposure()` in your fork. Every
replaceable part of Screenplay is picked the same way, like the
[Yjs host](/self-hosting/configuration/yjs-host).
