# Shared state

`@screenplay.space/state` bridges a piece of your app's state to the canvas.
Change it in one person's frame and every other viewer's frame updates too.
It's useful for things like the signed-in user, the selected plan, or a
billing toggle, so a whole team can look at the same screen in the same state.

The frame's route pill shows a `{}` when shared state is present. Hover it to
see the JSON. Screenplay doesn't edit shared state from the canvas; it only
displays it.

<Callout type="info">
  The agent knows this package through the `screenplay-share-state`
  [skill](/building/skills). Try "share the billing toggle with the canvas".
</Callout>

## Install

```bash
npm install @screenplay.space/state
```

React 17 or later is a peer dependency.

## Two-way sync

Pass the value **and** its setter to keep existing UI state in sync in both
directions:

```tsx
import { useState } from "react"
import { useSharedState } from "@screenplay.space/state"

export function BillingToggle() {
  const [annual, setAnnual] = useState(false)
  useSharedState("billing", annual ? "annual" : "monthly", (v) =>
    setAnnual(v === "annual"),
  )
  return <Toggle value={annual} onChange={setAnnual} />
}
```

This is the demo app's pricing page. Flip the toggle in one frame and every
frame on `/pricing` flips with it.

## Publish only

Leave out the setter to publish a value the canvas can see, but never write
back:

```tsx
const user = useUser()
useSharedState("user", user ? { id: user.id, role: user.role } : null)
```

## Without React

```ts
import {
  setSharedState,
  subscribeSharedState,
  clearSharedState,
} from "@screenplay.space/state"

const remove = setSharedState("session", { id: "u_1", role: "admin" })
const unsubscribe = subscribeSharedState("session", (next) => {
  console.log("session changed", next)
})

remove()                    // or clearSharedState("session")
unsubscribe()
```

## Rules

- Values must be **JSON**. Functions, class instances, `undefined`, and
  circular references are dropped.
- The combined state is capped at **64 KB**. Larger updates are skipped with a
  console warning.
- State is kept with the frame across reloads and carries into
  [play mode](/guides/play-mode). Keep keys stable, like `id`s: renaming a key
  drops the old entry.
- Like knobs, it's **development-only** and does nothing outside a Screenplay
  frame, so it's safe to ship. It works in Vite and other bundlers with no
  setup, [like knobs](/building/knobs#safe-to-ship).
