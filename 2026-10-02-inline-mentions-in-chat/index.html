What changes regardless of the pick

  • One inline reference style for every kind: icon first (it replaces the @), then the name, never underlined. Since round 3 that's no border or fill: a 14px medium name with the icon in the text colour.
  • A Workspace leads with its live state glyph: idle circle, spinner while setting up, 9-dot while working, orange dot when it needs you, check when done.
  • Documents, frames and mockups use the toolbar's icons. A picked element keeps its crosshair and mono name.
  • Coordinator replies can name frames, documents and mockups as references, the way they name Workspaces today. Clicking one fits it in your view on the canvas.
  • A drawn Mockup's ask reads "Sketch it in [Mockup], for a 390 × 844 viewport." with no marker text.
  • The composer and the document editor draw @ mentions the same way.
