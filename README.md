# Screenplay

A Next.js app that runs coding agents inside live development sandboxes with
real-time collaboration on a shared canvas.

## Documentation

Setup, deployment, configuration, and contributor docs live in the **docs site**
(`apps/docs`, dev-served on http://localhost:3002):

- **Getting Started** — clone the monorepo and run it locally
- **Deployment** — services, GitHub OAuth, Postgres, environment variables, Vercel
- **Configuration** — the swappable backends (sandbox, blob, Yjs, models, harnesses, mount path)
- **Development** — the contributor command reference

The docs site is the canonical home for all of the above; please add and update
documentation there rather than expanding this README.
