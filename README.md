# Screenplay

A canvas for building software with coding agents: every branch gets a live
environment, its app appears as real previews on an infinite canvas, and you
drive the agent from a chat beside it.

## Documentation

Setup, deployment, configuration, and contributor docs live in the **docs site**
(`apps/docs`, dev-served on http://localhost:3002):

- **Get started**: what Screenplay is, a quickstart, and core concepts
- **Using Screenplay**: canvases, projects, workspaces, frames, documents, agent
  chat, terminals, play mode, collaboration, settings, and keyboard shortcuts
- **Building for Screenplay**: the dev-server port contract, knobs, shared
  state, and agent skills
- **Self-hosting**: services, GitHub OAuth, Postgres, environment variables,
  Vercel, and every swappable backend
- **Development**: running from source and contributor commands

The docs site is the canonical home for all of the above; please add and update
documentation there rather than expanding this README.
