Chat Panel Navigation

With a Canvas chat added, the panel now has levels: the Canvas chat on top, then each Workspace with its chat and terminal tabs, plus documents. Today the header has one flat picker (TargetPicker: Workspaces, then Documents) and the tab strip under it. Here are four ways to move between the levels. Each is shown at the Canvas level, inside a Workspace, and in light and dark. They all use stock shadcn parts already in the panel.

The journey to judge: you're in the Canvas chat, you open hero-split from the fan-out card, you nudge its agent, and you go back to the Canvas.

What stays the same in every option

The tab strip keeps chats and terminal tabs together. The PR button and diff stats show only at the Workspace level. The Canvas level has no git controls, because it has no single branch. The left sidebar's Workspace rows keep opening that Workspace's chat.
