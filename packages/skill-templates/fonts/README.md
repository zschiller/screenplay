# Fonts

Latin subsets of the app's faces, inlined into `fonts.css` in each App Skill
that ships a template (`lib/fonts.ts`), so a page shown as a Mockup keeps the
Screenplay look without loading anything from the network.

- Instrument Sans (variable, weight 400–700, width 75–100%)
- Unbounded (400)
- Geist Mono (variable, 400–600)

All three are from Google Fonts under the SIL Open Font License 1.1.
