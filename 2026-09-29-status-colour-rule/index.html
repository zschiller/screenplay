Status Colour Rule

Status colour rule

After the Signal palette landed, status colour shows up in four different ways: tint, outline, fill and plain coloured text. Recording is a red tint, the lost-work warning is an outline, the plan and settings chips are tints, and pins and dots are fills. This page proposes one rule and asks three questions where the rule could go either way.

The proposed rule

Three treatments, no tints

Ink

Coloured text or icon on the normal surface. For a status word or icon that stands alone: PR state, +46 −4, the sidebar warning icon, inline errors under a field.

Outline

Border, regular text, coloured icon. For any box that carries a status message: chips, badges and banners. Same as the #482 PR chip and the lost-work banner today.

Fill

Solid neon with black on it. Only for small marks (dots, pins, the record dot, the done circle) and the one active mode button (Interact). Never behind a sentence.

Tints (bg-*/10) go away. Two exceptions stay tinted because the tint is the content, not a status: diff added and removed lines in the chat, and the canvas inspect overlay in the player.
