Your note on P4

Can an agent delete a skill today? Yes. Every chat has delete_skill, and the prompt tells it to use it (lib/agent/config.ts:219). It runs straight away with no card (lib/agent/skill-tools.ts:195-213). That includes Claude Code and Codex chats on the Mac: Screenplay pre-allows every tool on its server, so Claude Code doesn’t ask either (lib/agent/coordinator-mcp.ts:29-31, 126).

Can Claude Code do it on its own? Not with a skill tool. It has no tool for deleting skills, but it can remove a skill folder under ~/.claude/skills with a shell command. In its default mode it asks your permission first.

Should it? I’d keep the ability and put it behind the card, which is your pick A. “Delete that skill” in a chat is the natural way to ask, and it mirrors saving: the agent proposes and you press.
