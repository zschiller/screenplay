Top recommendation

Decide steerability once, as a fact about the run

Steering is where the runtime keeps breaking (#1196, #1197, #1209, and the open Codex queueing problem). Today four modules each decide whether a run takes a Steer and they disagree, so one message can land in three places depending on timing. Moving that fact onto the run gives one place to fix and one test surface for the Codex case.

Problem
