Coordinator task rows

When the Coordinator sends work to a Workspace, the chat shows one row per Workspace. Since the quiet-chat change these rows are a 12px muted line, the same weight as a finished turn's summary, so they read as metadata instead of the thing that happened. Four ways to give them more presence, each in both themes. The toggle flips Checkout polish between working and done.

A. Task cards Recommended

Each Workspace gets its own quiet card on the muted fill, like a thread card in Claude: state icon, title at body size in the regular text colour, then changed lines, the state in a word and a chevron at the right edge. No border. Hover goes to the accent fill. bg-muted px-2.5 py-2 text-sm, rows gap-1.

B. Cards with the message

A, plus a second muted line with what the Coordinator asked that Workspace to do. It answers "what is it doing?" without opening the Workspace, at the cost of height. It's the same idea as Claude Code's subagent line, which shows the task's description.

C. Full-width line with a status chip

The smallest change: the row stays borderless, but the title moves up to body size and the regular text colour, the row runs the full width with an accent hover, and the state sits at the right edge as an outline chip (the status colour rule's chip style).

D. One grouped list

The rows from one send go in one bordered list headed "Sent to 2 Workspaces", split by hairlines, like a task list in other agent tools. It groups well but adds the most chrome.
