Coordinator tool steps

On the Claude harness the Coordinator reaches its canvas tools over MCP, so its steps arrive as mcp__screenplay__read_canvas and ToolSearch in bordered code-style boxes, and opening one shows the raw text the model reads. Three ways to fix it, smallest first. B is the recommendation.

  • Raw names. The row label only knows our in-process names (read_canvas), not the MCP prefix the harness adds, so it prints the identifier verbatim with a terminal icon.
  • Harness plumbing. ToolSearch is Claude Code loading our tools. It means nothing to the person.
  • Model-facing output. Opening a row shows ids like ws_8f2a and frm_1 that exist for the model.
  • Workspace chat chrome. The bordered, expandable boxes suit a coding agent's file reads. The Coordinator's steps are lookups, not work you want to audit.
