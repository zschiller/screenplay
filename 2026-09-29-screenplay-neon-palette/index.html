Screenplay · colour exploration · 29 Sep 2026

Every colour as loud as the magenta

Three ways to bring green, amber, red and merged-purple up to the magenta's intensity, with black text and icons on every solid fill. Hues stay where people expect them: green is open or good, purple is merged, red is closed or failed, amber is attention. Magenta itself is unchanged in every option.

Each option shows the same real pieces of the app in light and dark: the chat header PR button, Workspace rows, status badges, the canvas selection tag and comment pins, setup steps, connection dots and the destructive button.

Round 2 · Signal follow-ups

Magenta fills and the Delete button

Black on the full magenta measures 5.9:1 but still reads dark and muddy. These options keep the magenta for selection outlines, focus rings and text, and use a lighter pink only where black text sits on it. Below that are four styles for Delete, shown in a confirm dialog footer and as a row action.

Notes for all options
  • Solid fills always carry black (the Interact tag, comment pins, setup "done" circles and status badges switch from white today).
  • The destructive button stays the stock shadcn tinted variant; only its red changes.
  • Merged purple moves to hue 293, a step bluer than GitHub's, so it doesn't blur into the magenta (hue 322) when both sit in one row. Element picking on the canvas takes the same violet.
  • Values stay inside sRGB. The desktop app on a P3 display could go roughly 10% more saturated if you want it even louder.
  • Syntax highlighting in chat code blocks and diff colours are left out; they follow GitHub's theme.
