Chat panel

1

One Kbd per key in Create workspaces

Screen: new-workspace-multi · create-branch-dialog.tsx:303

"Add another" shows ⌘↵ as one key cap, which breaks the house rule of one Kbd per key.

Change: render ⌘ and ↵ as two caps in a KbdGroup. The single ↵ on the primary button stays.

Chat tabs show more of their title

Screens: hero, play-agent, new-tab-menu, doc-chat · chat-panel.tsx:289 (max-w-[100px])

Tab titles cut off at 100px even when the strip is mostly empty ("Hero Gradient &…", "Launch Checkli…").

Change: raise the label cap to 180px. Tabs still shrink to their 100px minimum when the strip fills up.

Terminal tab label in the chat font

Screen: terminal · chat-panel.tsx:347

Terminal tabs sit beside chat tabs (terminals are chats when running a harness), but their label is monospace, so the strip mixes two fonts.

Change: use the same sans label as chat tabs. The terminal icon already tells them apart.

4

Terminal and logs share the chat gutter

Screens: terminal, logs, hero · use-terminal-pane.ts:320 (8px), logs-panel.tsx:305 (12px, leading-relaxed)

Chat text starts 16px in, logs 12px, terminal 8px, so switching tabs makes the text jump sideways. Logs also use looser line spacing than the terminal.

Change: inset terminal and logs text to the chat's 16px gutter, and give logs the terminal's line height. The dashed line marks the chat gutter.
