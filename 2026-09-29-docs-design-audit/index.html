The docs site against the app's design system

The docs run on Nextra 4 and still wear most of Nextra's own chrome: its cool grey palette, tinted callouts, a single "⌘K" keycap, frosted-glass menus and a pink search highlight. Each finding below is prototyped as CSS on a production build of apps/docs (so search works), shown before and after at 1440px. Every fix stays inside the current layout.
