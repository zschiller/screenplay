Problem
Membership is checked by habit: compareBranches and listBranchPrs write to the room doc with no requireMember, and the stream and branch-create routes check only that someone is signed in.
Solution
One Room Access module turns (session, roomId) into room reads and writes; mutateRoomDoc stops being importable from action files.

  • leverage: 19 action files, one check
  • one PGlite suite covers member / non-member / local

Top recommendation

Start with Room Access

It closes a real authorization gap on the hosted build today, it's the smallest seam with the most callers, and Comment Threads (6) builds directly on it. After that, Turn Launch is the biggest locality win in the agent runtime and unlocks server-side auto-naming (3).
